Langue
Langue de l'interface : popup, carte de rappel, étapes et infobulle de l'icône. Le changement s'applique tout de suite, sans recharger.
Raccourci clavier
Raccourci actuel : …. Pour le modifier, ça se passe dans les réglages d'extensions de Chrome. Dans le sas, 1 2 3 répondent switch / file / laisser tomber sans la souris.
Aucun raccourci n'est assigné à Airlock. Chrome n'a pas pu lui donner … : la combinaison est sans doute déjà prise par Chrome, une autre extension ou une application. Choisis une combinaison libre avec le bouton ci-dessous. L'extension fonctionne : en attendant, un clic sur son icône ouvre le sas.
Rappel du focus sur tous les sites …
Par défaut, la carte qui rappelle ton focus n'apparaît que sur claude.ai. Active-la partout pour la retrouver là où l'attention s'échappe vraiment : mails, réseaux, vidéos, recherche. Elle n'apparaît que si un focus est défini, se ferme d'un clic, et ne lit jamais le contenu des pages. Chrome te demandera l'accès aux sites : c'est ce qui permet d'afficher la carte, rien d'autre.
Export / Import
Tes données restent 100% locales. L'export (focus, file, historique daté, étapes) sert de sauvegarde ou de transfert manuel vers une autre machine.
